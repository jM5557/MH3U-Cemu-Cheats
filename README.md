Cheats can be added and enabled on the following custom Cemu build: 
- PC (Linux/SteamOS/Windows): https://github.com/jM5557/Cemu-Enhanced
- Android: https://github.com/jM5557/Cemu-Android-MH3U-Revival

Note: Always make a backup copy of your save data before enabling new or untested cheats!

# Compatibility
- Monster Hunter 3 Ultimate v32 EUR (Title ID: 0005000010117200) 

# Includes
- Full Equipment Box in Port Tanzia: QOL Improvement - Change equipment, appearance, and equipment sets directly from the Port Tanzia Tavern item box.
<br>Works perfectly when playing offline. When playing in multiplayer, for others to see your newly equipped gear you must exit and re-enter the Tavern (can simply move to the Marina and then back to the Tavern).

- Many Zenny (999,999z): Cheat - Changes your Zenny amount to 999,999. For any other amount change `000F423F` in the cheat code to a numeric decimal value converted to hexadecimal.

- Hold "A" to Carve/Mine/Gather: QOL Improvement - Hold the "A" button when carving or gathering the same as in modern MH titles

- Smooth vertical camera (underwater-style): QOL Improvement - Tilting the camera on land vertically up or down is now smooth instead of limited (adapted from the underwater camera controls)
